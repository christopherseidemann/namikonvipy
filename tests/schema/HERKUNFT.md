# Herkunft des Schemas

`pain.008.003.02.xsd` ist das Schema für SEPA-Lastschriften aus der Anlage 3 des
DFÜ-Abkommens der Deutschen Kreditwirtschaft (Version 2.7, gültig ab November 2013).
Offizielle Quelle: https://www.ebics.de/de/datenformate

Die Datei wird nur von den Tests benutzt, um das erzeugte XML zu prüfen.
Sie steht nicht unter der MIT-Lizenz dieses Repos.
